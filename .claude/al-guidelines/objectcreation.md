- Evertime you make a new table, you also need to create the Page List and Page Card for it.
- Once you have created the pages, you need to specify the CardPageId on the Page List
- Once you have created the pages, you need to specify the lookuppageid property on the table, making it point to the Card Page if the table is an entity, or to the List Page if the table is an Entry.
- Always define the property Caption and ToolTip at the field level in the table, don't do it at the Page.
- Only add ApplicationArea = All (For pages) or DataClassication = CustomerContent (for tables) in the field level for tableextensions or pagextensions, if not, onyl add it at the top at the object level.
- If you are going to create an option field, instead create an enum object and set it as the data type.
- Everytime you create any new type of object, include it on the permissionset object. If you dont find one, then create the permissionset object frist.
- You need to always keep in memory what is the last Object ID used for each type of object, and use the next one when you create a new object
- When creation new Actions on page or pageextensions, if you want to promote an action, do not use Promoted or PromotedCategory, but use actionref
